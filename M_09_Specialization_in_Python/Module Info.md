## Module Overview

### Objectives
- Understand file handling in Python — opening, reading, writing, and appending files.
- Learn various file access modes and apply them in real-world scenarios.
- Perform advanced file operations such as removing lines, finding odd/duplicate lines, and merging files.
- Introduction to Tkinter — Python's standard GUI library.
- Build interactive GUI applications using Tkinter widgets (labels, buttons, images, message boxes).
- Develop a complete Denomination Calculator GUI application using Tkinter.

### Lesson Highlights
- **Lesson 49:** Introduction to file handling; open files in various modes; read, write, and append content; understand access modes.
- **Lesson 50:** Read file contents in multiple ways; perform line-level operations like removing specific lines and extracting odd-numbered lines.
- **Lesson 51:** Advanced file operations including identifying duplicate lines and merging multiple files into one.
- **Lesson 52:** Set up a Tkinter window; add basic widgets; understand the event loop and layout management.
- **Lesson 53:** Work with Tkinter widgets — display images, create alert dialog boxes, and manage window properties.
- **Lesson 54:** Build a fully functional Denomination Calculator using Tkinter to combine all GUI concepts learned.
