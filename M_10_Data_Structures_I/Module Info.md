## Module Overview

### Objectives
- Understand the concepts of time and space complexity in algorithm design.
- Analyse algorithms using Big O, Big Theta, and Big Omega (asymptotic) notation.
- Evaluate recursive and iterative algorithms for their time and space complexity.
- Apply mathematical reasoning to solve number-based programming challenges.
- Implement classic algorithms such as GCD, palindrome checking, prime detection, and the Sieve of Eratosthenes.
- Solve conversion problems including Roman numerals to integers and binary to decimal.

### Lesson Highlights
- **Lesson 55:** Introduce the idea of measuring algorithm efficiency; compare multiple approaches to the same problem; understand iterative complexity.
- **Lesson 56:** Learn O(1), O(n), and O(n²) time complexities with practical code examples; understand asymptotic notation.
- **Lesson 57:** Analyse recursive algorithms for time complexity; understand space complexity and memory usage.
- **Lesson 58:** Apply mathematical knowledge to problem-solving — Armstrong numbers, factorials, and Roman numeral conversion.
- **Lesson 59:** Work with classic number problems — palindromes and GCD using the Euclidean algorithm.
- **Lesson 60:** Explore prime number theory — primality tests, the Sieve of Eratosthenes, and finding 2-digit primes.
