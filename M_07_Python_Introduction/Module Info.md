## Module Overview

### Objectives
- Set up Python development environment (Repl.it/online IDEs) and understand program structure.
- Learn Python data types and operators, and manipulate strings and numbers.
- Practice conditional statements and use the DateTime module for date/time operations.
- Write loops to generate patterns and compute series.
- Define and use functions; build small utilities like calculators and factorials.
- Explore `turtle` graphics to draw shapes and create simple animations.

### Lesson Highlights
- **Lesson 37:** Intro to Python syntax, running code on Repl.it, and simple flowcharts for decision making.
- **Lesson 38:** Understanding types (int, float, str, bool), operators, and basic string handling.
- **Lesson 39:** Conditional logic (if/else/elif) and simple date/time operations.
- **Lesson 40:** For and while loops; pattern printing and prime checks.
- **Lesson 41:** Writing reusable functions, parameters, return values, and simple calculators.
- **Lesson 42:** Introduction to `turtle` graphics — drawing basic shapes and spirals.
